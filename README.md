# 🌟 Personalized Insurance Clustering System

이 레포지토리는 개인화된 보험 추천 시스템을 위한 코드와 분석자료를 포함하고 있습니다.    
🛠️ 이 시스템은 클러스터링 알고리즘을 활용하여 상세한 보험 담보 코드를 분석하고 사용자 맞춤형 보험 옵션을 제안합니다. 💡

## 📂 프로젝트 구조

### 📁 파일 및 노트북

1. **DBSCAN.ipynb**
   - 🌀 DBSCAN(Density-Based Spatial Clustering of Applications with Noise) 알고리즘을 구현하여 보험 데이터의 담보 패턴을 기반으로 그룹화합니다.

2. **Fuzzy.ipynb**
   - 🌈 퍼지 클러스터링 기법을 활용하여 보험 선호도와 담보 요구 사항에서 중복되는 패턴을 식별합니다.

3. **K-Means_Plus.ipynb**
   - 📊 기존 K-Means 알고리즘을 개선하여 추가 최적화 기술로 보험 담보 클러스터를 분석합니다.

## 🛠️ 사용 방법

1. 레포지토리 클론:
   ```bash
   git clone https://github.com/yourusername/your-repository.git
   ```
2. 프로젝트 디렉토리로 이동:
   ```bash
   cd your-repository
   ```
3. 필요한 의존성을 설치합니다. Python 3.x 및 Jupyter Notebook이 설치되어 있어야 합니다. 그런 다음 다음 명령을 실행하세요:
   ```bash
   pip install -r requirements.txt
   ```
4. 원하는 노트북을 Jupyter Notebook에서 열기:
   ```bash
   jupyter notebook
   ```
5. 각 노트북의 지침에 따라 클러스터링 알고리즘을 실행하세요.
